### Planning Design

When trying to find the desired layout for my website, I came across a list of bootstrap templates that caught my eye. One of those being an album template with cards and a drop down to view links and extra information. I changed the content of the template to fit my usecase for it:

![Initial Example](/doc-images/pic1.png)

Once I had done this I didn't feel like it was my website, so I wanted to add some personalization to it. Claude code is very good at generating visuals for this purpose. I gave a semi-detailed prompt that laid the groundwork for the styling of my website:

#### Prompt
```I would like a few different style boards with a color palette of gray, purple and black. Background being greyish purple and and the darker gray components should be purplish gray. I want to add margins to the page and maybe change the font. Along with the style boards and possible color palettes, give me some component comparisons on the detail elements and the title. If you have any questions, ask before starting and dont give me anything other than what I have asked.```


#### Result

It gave me 3 options for 3 different parts of the design: the color palette, title styling, and detail styling. Since I gave more detail on the color palettes and not the other components, they were the closest to what I envisioned. It outputted color palettes very similar to eachother, only slightly changing the shades of the colors. The title and detail elements were quite varied and it gave me more ideas for the overall design. To view the source file and preview these designs [Click Here!](examples.html)
